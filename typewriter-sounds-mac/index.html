How the bell and Return work

On a real typewriter the margin bell rings a few characters before the end of the line, as a warning, and then you throw the carriage return. A Mac has no margin, so Keyslam rings on Return (and the keypad Enter key), the moment a line actually ends.

  • Selectric: Return plays 2.5 s of an antique typewriter's bell and carriage return, from “Typewriter bell & carriage reset” by knufds. The Selectric in the main recording had a broken bell.
  • Olivetti: Return plays a bell, 1.0 s long, from “Typewriter ding_near_mono.wav” by _stubb.
  • Every Return rings. It's the same bell recording each time; pressing harder plays it louder, not differently. There's no setting to ring it after a set number of characters.
  • Space and Delete use the same strikes as the letter keys.
  • No key-up sounds. A typewriter key makes its noise on the way down, so both packs stay silent when you let go.

Selectric or Olivetti?

Pick the Selectric if you want an office electric. The motor does the striking, so its strikes vary less than the Olivetti's, and Return plays a bell followed by a carriage return.

Pick the Olivetti if you want the feel of a manual. Its strikes vary the most: the slam band plays 14.3 dB above the soft band, the widest range of the boards we measured. On a MacBook with the motion sensor, a light tap and a hard hit sound like two different keystrokes.

Typewriter sounds while you type, in any app

A typewriter sound effect file plays once. A typewriter app plays a strike for every key you press. Keyslam does that system-wide: in Pages, Word, Google Docs, Notes, Mail, a code editor or a chat window. It's how to make your keyboard sound like a typewriter without touching the keyboard.

  1. Install Keyslam from the download page, and open it from the menu bar.
  2. Allow Input Monitoring in System Settings › Privacy & Security. Keyslam only uses which key went down; it never stores or sends what you type.
  3. Choose Selectric or Olivetti in the Sound grid.
  4. Set the strength. On MacBooks with the motion sensor, keep “Feel how hard you type” on. On other Macs, pick Soft, Medium, Hard or Slam.
  5. Type. Press Return at the end of a line for the bell.

The two typewriters come with every other board in Keyslam, a keyboard sound app for Mac that runs on macOS 13 Ventura or later, Apple silicon or Intel. It makes no network connections and plays through your speakers or headphones.

Typewriter sounds: questions

Can I make my Mac keyboard sound like a typewriter?

Yes. Choose Selectric or Olivetti in Keyslam and every key you press plays a real typewriter strike in any app, with a bell on Return. It works with the built-in keyboard and with external keyboards.

Does the typewriter bell ring at the end of every line?

It rings every time you press Return, because that's where a line ends on a Mac. Unlike a real margin bell, it doesn't count characters or warn you before the margin.

Do the typewriter keys make a sound when I let go?

No. A typewriter's noise is the strike on the way down, so the Selectric and Olivetti packs have no key-up sounds. The keyboard packs do.

Does it work in Pages, Word and Google Docs?

Yes. Keyslam plays on every key you press, whichever app is in front. macOS keeps password fields private, so those stay silent.
